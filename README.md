# Stochastic Simulation for Bayesian Modeling in Psychology

Online version of *Stochastic Simulation for Bayesian Modeling in Psychology: An Introduction to Computational Methods* by Maarten Marsman and Lourens Waldorp.

Read it at <https://maartenmarsman.github.io/computational-methods-book/>. Comments and corrections are welcome as [issues](https://github.com/MaartenMarsman/computational-methods-book/issues).

## Versions

Nothing is released yet. Each released version of the book gets a number, stays online, and has an entry on the News page that says what changed since the version before it. A correction to released text is itself a new version, so nothing changes silently under a reader.
