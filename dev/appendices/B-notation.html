Appendix B — Notation

This appendix collects the symbols used for data, probability distributions, Markov chains, and sampling algorithms throughout the book.

B.1 Conventions

Probability functions. We write \(f(\cdot)\) for probability mass functions and densities. The arguments distinguish the prior \(f(\theta)\), the likelihood contribution \(f(y\mid\theta)\), and the posterior \(f(\theta\mid y)\). In descriptions of a sampler, \(f(\theta)\) can instead denote the chosen target density. A proportion parameter is written \(\pi\); the proposal density has its own symbol \(q\).

Work on the log scale. Where a sampler takes a target-density function, we supply its logarithm, typically called log_target or log_posterior. Products of many small likelihood contributions can round to zero; logarithms let us add their values instead. A log density ratio is a difference, \(\log r=\log f(\theta^\star)-\log f(\theta^{(t)})\), and the acceptance test becomes \(\log u<\log r\) (Chapter 5). R’s density functions can compute log densities directly with log = TRUE.

Vectors are bold, indices are subscripts, iterations are superscripts. A single parameter is \(\theta\); a vector of parameters is \(\boldsymbol{\theta} = (\theta_1, \ldots, \theta_d)\); a matrix is a bold capital such as \(\mathbf{P}\) or \(\boldsymbol{\Sigma}\). Observations are indexed \(i = 1, \ldots, n\), predictors \(j = 1, \ldots, p\), and models \(m = 1, \ldots, M\). The state of a Markov chain at iteration \(t\) is \(\theta^{(t)}\), with parentheses so that it is not mistaken for a power; a proposed value is \(\theta^\star\). The starting state is indexed \(t=0\). A run recording \(N\) sampled states has updates \(t=1,\ldots,N\); summaries after warm-up use the retained states. Hats denote estimates computed from draws, as in \(\widehat{R}\).

B.2 Data, parameters, and densities

Symbol Meaning
\(y\), \(\mathbf{y} = (y_1, \ldots, y_n)\) observed data; \(n\) observations
\(\mathbf{X}\), \(x_{ij}\) design matrix with \(n\) rows and \(p\) predictors
\(\theta\), \(\boldsymbol{\theta}\) a generic parameter; a vector of \(d\) parameters
\(\pi\) a proportion parameter
\(\mu\), \(\sigma\), \(\sigma^2\) a mean, a standard deviation, a variance
\(\beta_0, \beta_1, \ldots, \beta_p\) regression coefficients
\(f(\theta)\) prior density
\(f(y \mid \theta)\), \(L(\theta \mid y)\) likelihood; the same function read as a function of \(\theta\)
\(f(\theta \mid y)\) posterior density
\(f(y) = \int f(y \mid \theta) f(\theta) \, d\theta\) marginal likelihood, the normalizing constant of the posterior
\(f(\theta \mid y) \propto f(y \mid \theta) f(\theta)\) the unnormalized posterior, which is all a sampler needs
\(E[g(\theta) \mid y]\) a posterior expectation, the thing Monte Carlo estimates (Chapter 1)
\(\text{BF}_{01} = f(y \mid \mathcal{M}_0) / f(y \mid \mathcal{M}_1)\) Bayes factor for model \(\mathcal{M}_0\) against \(\mathcal{M}_1\) (Chapter 2)

B.3 Markov chains and samplers

Symbol Meaning
\(\theta^{(t)}\) state of a Markov chain at iteration \(t\); \(\theta^{(0)}\) is the starting value
\(N\) number of sampled states; for summaries after warm-up, the count refers to retained states
\(m\), \(L\) number of chains and retained states per chain; with equal chain lengths, \(N=mL\) (Chapter 4)
\(\theta^\star\) a proposed value
\(q(\theta^\star \mid \theta)\) proposal density; symmetric in the Metropolis algorithm, general in Metropolis–Hastings
\(r\) acceptance ratio, \(f(\theta^\star) / f(\theta^{(t)})\) for a symmetric proposal
\(\alpha(\theta, \theta^\star) = \min\{1, r\}\) acceptance probability
\(u \sim \text{Unif}(0, 1)\) the uniform draw that decides acceptance
\(c\) step size of a random-walk proposal, \(\theta^\star \sim \text{N}(\theta^{(t)}, c^2)\)
\(\alpha^\ast\), \(\gamma_t\) target acceptance rate and learning rate in Robbins–Monro adaptation (Chapter 6 (Metropolis–Hastings and Adaptive Proposals))
\(\mathbf{P}\), \(P_{ij}\) transition matrix of a discrete chain; probability of moving from state \(i\) to state \(j\) (Chapter 3)
\(K(\theta, \theta')\) transition density between distinct states of a continuous chain; rejections also give a probability of staying at the current state
\(\boldsymbol{\pi}\) stationary distribution of a discrete chain, a row vector with \(\boldsymbol{\pi} \mathbf{P} = \boldsymbol{\pi}\)
\(f(\theta) K(\theta, \theta') = f(\theta') K(\theta', \theta)\) detailed balance with respect to \(f\)
\(f(\theta_j \mid \boldsymbol{\theta}_{-j}, y)\) full conditional of \(\theta_j\) given all other parameters (Chapter 7 (Gibbs Sampling and Metropolis-within-Gibbs))
\(\rho_k\) autocorrelation of a chain at lag \(k\) (Chapter 4)
\(\text{ESS}\) effective sample size; the equivalent independent-draw count for the precision of a specified summary
\(\widehat{R}\) R-hat, a diagnostic comparing behavior within and between chains; use a value below 1.01 alongside the other checks in Chapter 4
\(\text{MCSE}\) Monte Carlo standard error of an estimated summary; for a mean, approximately \(\text{sd}/\sqrt{\text{ESS}}\)

B.4 Model uncertainty

Symbol Meaning
\(\mathcal{M}_m\), \(m = 1, \ldots, M\) model \(m\) out of \(M\) candidate models (Chapter 8 (Bayesian Variable Selection))
\(\gamma_j \in \{0, 1\}\) inclusion indicator for predictor \(j\): \(\gamma_j = 1\) means \(x_j\) is in the model
\(\boldsymbol{\gamma} = (\gamma_1, \ldots, \gamma_p)\) a model, written as its vector of indicators; there are \(2^p\) of them
\(f(\mathcal{M}_m)\), \(f(\mathcal{M}_m \mid y)\) prior and posterior model probabilities
\(f(y \mid \mathcal{M}_m)\) marginal likelihood of model \(m\)
\(P(\gamma_j = 1 \mid y)\) posterior inclusion probability of predictor \(j\)
\(f(\theta \mid y) = \sum_m f(\theta \mid y, \mathcal{M}_m) f(\mathcal{M}_m \mid y)\) model-averaged posterior (Chapter 9 (Bayesian Model Averaging))

B.5 Hamiltonian Monte Carlo

Symbol Meaning
\(\mathbf{p}\) momentum, an auxiliary vector of the same length as \(\boldsymbol{\theta}\) (Chapter 10 (Hamiltonian Monte Carlo))
\(\mathbf{M}\) mass matrix, the covariance of the momentum, \(\mathbf{p} \sim \text{N}(\mathbf{0}, \mathbf{M})\)
\(H(\boldsymbol{\theta}, \mathbf{p}) = -\log f(\boldsymbol{\theta}) + \tfrac{1}{2} \mathbf{p}^\top \mathbf{M}^{-1} \mathbf{p}\) the Hamiltonian: potential energy plus kinetic energy
\(\nabla \log f(\boldsymbol{\theta})\) gradient of the log target, the grad_log_target argument of hmc()
\(\varepsilon\) leapfrog step size
\(L\) number of leapfrog steps per proposal; trajectory length is \(\varepsilon L\)

Plain \(\pi\) denotes a proportion, while bold \(\boldsymbol{\pi}\) denotes a stationary probability vector. In geometric formulas and Normal densities, \(\pi\) can also be the mathematical constant \(3.14\ldots\). Similarly, \(\gamma_j\) with a predictor index denotes an inclusion indicator, while \(\gamma_t\) with an iteration index denotes a learning rate. The context and index distinguish these uses.

B.6 Distributions

The table gives the distribution notation and parameterizations used in this book. The last column gives the R function that computes the density, because you will write log posteriors as sums of d*(..., log = TRUE) calls, and R’s argument names do not always match the mathematical parameters. Two traps: the Normal is written with its variance \(\sigma^2\) but dnorm() takes the standard deviation sd, and the Gamma and Exponential are written with a rate, which is what dgamma() and dexp() take by default, not a scale. The r* function with the same name and arguments draws random values.

Notation Parameters Density in R
\(\text{N}(\mu, \sigma^2)\) mean \(\mu\), variance \(\sigma^2\) dnorm(x, mean = mu, sd = sigma)
\(\text{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})\) mean vector, covariance matrix mvtnorm::dmvnorm(x, mean = mu, sigma = Sigma)
\(\text{Beta}(\alpha, \beta)\) shape parameters \(\alpha, \beta > 0\); mean \(\alpha/(\alpha + \beta)\) dbeta(x, shape1 = alpha, shape2 = beta)
\(\text{Gamma}(s, r)\) shape \(s\), rate \(r\); mean \(s/r\) dgamma(x, shape = s, rate = r)
\(\text{Inverse-Gamma}(s, r)\) shape \(s\), rate \(r\); \(1/X \sim \text{Gamma}(s, r)\) no base function; dgamma(1/x, s, r, log = TRUE) - 2 * log(x)
\(\text{Exponential}(\lambda)\) rate \(\lambda\); mean \(1/\lambda\) dexp(x, rate = lambda)
\(\text{Unif}(a, b)\) lower and upper bounds dunif(x, min = a, max = b)
\(\text{Cauchy}(m, s)\) location \(m\), scale \(s\) dcauchy(x, location = m, scale = s)
\(\text{Laplace}(m, b)\) location \(m\), scale \(b\) no base function; -log(2 * b) - abs(x - m) / b on the log scale
\(\text{Bernoulli}(\pi)\) success probability \(\pi\) dbinom(x, size = 1, prob = pi)
\(\text{Binomial}(n, \pi)\) number of trials \(n\), success probability \(\pi\) dbinom(x, size = n, prob = pi)
\(\text{Poisson}(\lambda)\) rate \(\lambda\); mean and variance \(\lambda\) dpois(x, lambda = lambda)

For example, check the distinction between variance and standard deviation in the Normal notation, and between shape and rate in the Gamma notation. The \(\text{N}(7, 0.5^2)\) prior of Chapter 5 has standard deviation \(0.5\), and a \(\text{Gamma}(2, 4)\) variable has mean \(2/4\):

set.seed(84735)
dnorm(7, mean = 7, sd = 0.5, log = TRUE)
[1] -0.2257914
mean(rgamma(1e5, shape = 2, rate = 4))
[1] 0.5018234
